Fixes macOS saying Tengen "is damaged and can't be opened" when opened after downloading. The app is now signed (ad hoc, without an Apple developer certificate), so macOS offers the usual way to open it.

**Download** `Tengen-1.0.1-AppleSilicon.dmg` below, open it and drag Tengen to Applications, replacing 1.0.0 if you have it. The first time you open it, close the warning macOS shows, then go to **System Settings → Privacy & Security** and choose **Open Anyway** next to Tengen. After that it opens normally.

Everything else is as in [1.0.0](https://github.com/rrivera1849/tengen/releases/tag/v1.0.0).
